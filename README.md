# 🤖 Telegram Bot - Умный помощник с напоминаниями

## 🚀 О проекте
Профессиональный Telegram-бот, разработанный на Spring Boot, предоставляющий интеллектуальные услуги: управление напоминаниями, мониторинг финансовых данных и получение актуальной метеоинформации.

## 💻 Технологический стек

### 🏗️ Backend
- **Java 17** - современная версия языка
- **Spring Boot 2.6.5** - основной фреймворк
- **Spring Data JPA** - работа с базой данных
- **Hibernate** - ORM mapping
- **Maven** - управление зависимостями

### 🗄️ База данных
- **PostgreSQL** - реляционная СУБД
- **Миграции через Hibernate** - автоматическое управление схемой

### 🔌 Внешние API
- **Telegram Bot API** - интеграция с мессенджером
- **Центральный Банк РФ** - получение курсов валют
- **OpenWeatherMap** - метеоданные (в разработке)

### ⚙️ Инфраструктура
- **Переменные окружения** - безопасное хранение конфиденциальных данных
- **Логирование** - детальный мониторинг работы приложения

## 🎯 Ключевые возможности

### ⏰ Умные напоминания
- Парсинг естественного ввода дат и времени
- Валидация и проверка корректности данных
- Надежное хранение в PostgreSQL
- Автоматическая отправка уведомлений

### 💵 Финансовый мониторинг
- Реальное время: курс USD/RUB от ЦБ РФ
- Автоматическое ежедневное обновление
- Красивое форматирование ответов

### 🌤️ Метеоданные
- Интеграция с OpenWeatherMap API
- Детальная информация о погоде в Томске
- Поддержка русского языка

## 🛡️ Безопасность и надежность

- **Защита конфиденциальных данных** через переменные окружения
- **Валидация входных данных** - защита от некорректного ввода
- **Обработка исключений** - стабильная работа при ошибках внешних API
- **Логирование** - полный мониторинг всех операций

## 📊 Архитектурные особенности

- **RESTful сервисы** - интеграция с внешними API
- **Слоистая архитектура** - разделение ответственности
- **Патерн Repository** - абстракция работы с данными
- **Событийный подход** - обработка Telegram webhook'ов

## 🚀 Производительность

- **Пуллинг обновлений** - мгновенная реакция на сообщения
- **Кэширование** - оптимизация запросов к внешним API
- **Пакетная обработка** - эффективная работа с уведомлениями
